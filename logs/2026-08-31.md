# สรุปสถานการณ์ตลาดหุ้น — 31 สิงหาคม 2026

## 🇹🇭 SET Index (ตลาดหุ้นไทย)
- **ระดับดัชนี:** 1,590.67 จุด (ช่วงเช้า)
- **การเปลี่ยนแปลง:** +2.45 จุด (+0.15%)
- **แนวรับ/แนวต้าน:** แนวรับ 1,580 / 1,550 จุด — แนวต้าน 1,600 จุด

**ปัจจัยหนุน (ตามบทวิเคราะห์ UOB Kay Hian Securities):**
1. หุ้นกลุ่มอิเล็กทรอนิกส์/เซมิคอนดักเตอร์ ยังได้แรงหนุนต่อเนื่องจากงาน "Thailand Focus 2026"
2. หุ้นกลุ่มโรงไฟฟ้า ได้รับความสนใจจากกระแสคาดการณ์แผน PDP (Power Development Plan) ฉบับใหม่ที่ใกล้สรุป
3. หุ้นกลุ่มธนาคารปรับขึ้นก่อนช่วงจ่ายเงินปันผล แต่มีความเสี่ยงถูกทำกำไรช่วงบ่ายเนื่องจากราคาขึ้นมาค่อนข้างมากแล้ว

## 🇺🇸 ตลาดหุ้นสหรัฐฯ (ปิดล่าสุด ศุกร์ที่ 28 ส.ค. 2026)
- **S&P 500:** ปิดที่ 7,711.76 จุด (-0.25%)
- **Nasdaq Composite:** ปิดที่ 26,402.42 จุด (-0.52%)
- **Dow Jones:** ปิดที่ 53,560 จุด (-9 จุด, -0.02%)

**ภาพรวมรายสัปดาห์:** แม้ปิดลบวันศุกร์ แต่รวมทั้งสัปดาห์ S&P 500 ยังบวก +0.5% / Nasdaq +0.9% / Dow +0.5% (สัปดาห์บวกครั้งแรกในรอบ 3 สัปดาห์)

**ปัจจัยกดดัน:** ท่าทีค่อนไปทาง Hawkish ของประธานเฟด Warsh ที่เน้นย้ำความกังวลเรื่องเงินเฟ้อ ทำให้ตลาดคาดการณ์มีโอกาสขึ้นดอกเบี้ยในการประชุมเดือนถัดไปมากขึ้น กดดันหุ้นกลุ่มเซมิคอนดักเตอร์ให้ย่อตัวลงจากที่เคยปรับขึ้นแรงในสัปดาห์ก่อนหน้า (แรงหนุนจาก Nvidia ที่ให้ guidance รายได้ดีในวันพฤหัสฯ)
