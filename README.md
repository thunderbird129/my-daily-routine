# my-daily-routine

Private daily briefing page, generated automatically every day at 7:00 AM (Asia/Bangkok).

Contents each day:
- Prices + recent news for the tracked stock watchlist
- Overview of yesterday's Outlook mail (sucharsi@scg.com)
- Today's calendar

Latest page: `index.html`. Past days are kept under `logs/YYYY-MM-DD.html`.

This repo is **private** and GitHub Pages is **not enabled** — the page is not publicly reachable.
Open `index.html` locally (or view it on GitHub, sign-in required) to read the latest briefing.
